Adds AliceSoft System 4 games on Mac, iPhone and iPad, and cheats for RPG Maker XP, VX, VX Ace and Wolf RPG Editor games.

## Downloads

- `VNDegen-0.15.0-macOS.zip` for Mac (macOS 15 or later). It is ad-hoc signed: right-click VNDegen and choose Open the first time, or run `xattr -dr com.apple.quarantine /Applications/VNDegen.app`.
- `VNDegen-0.15.0.ipa` for iPhone and iPad (iOS 18 or later). Update it from the AltStore or SideStore source (`https://raw.githubusercontent.com/ChronoStriker1/vndegen/main/altstore/source.json`), or sideload it with Sideloadly.

## New: AliceSoft System 4

- AliceSoft System 4 games run on VNDegen's own System 4 runtime, written in C++ for VNDegen from AliceSoft's System 4 SDK, the games' files and the original engine's behaviour, MIT licensed like the rest of the app. `docs/system4-cleanroom.md` lists its sources.
- Rance 02 and Sengoku Rance play, with their opening movies, battles and menus.
- Saves are the PC games' own files, so a save moves between VNDegen and a PC copy of the game in both directions.
- Files are found whatever case the game names them in.
- Games built on PartsEngine, such as Rance IX, aren't supported yet. Their game page says so.

## New: more cheats

- RPG Maker XP, VX and VX Ace games get the same Cheats page as MV and MZ: gold, items, keep HP and MP full, no random encounters, walk through walls, 2x or 4x speed, experience, and the variable and switch editor. Saves made afterwards load on the PC.
- Wolf RPG Editor games get a Variables tab, walk through walls and game speed. Games built on the editor's standard systems also get gold, items, weapons and armor, and restoring the party's HP and SP. Saves made afterwards stay ordinary Wolf saves.

## Fixes and changes

- AliceSoft System 3 and 4: the game clock no longer runs 2% fast. Animations and timers had been sped up by rounding each display refresh up.
- Wolf RPG Editor: a map event's parallel script restarts when its page changes, as on the PC.
- NScripter: a text speed chosen in Game commands is kept after the game quits.
- Ren'Py on iPhone and iPad: VNDegen's menu offers Quick save and Quick load only when the game's own quick menu lacks them.
- Flash: Ruffle's play button no longer shows under the VNDegen menu.
- RPG Maker XP and VX Ace: saves made on the PC are checked to load in VNDegen.
- The README is shorter, with the details in new docs, and shows the library layouts on each device.

## Known limits

- AliceSoft System 4: the openings can't be skipped the first time a game runs, and a controller button released after switching apps can also release a keyboard key of the same name. `docs/system4.md` has the rest.
- The cheats' variable and switch editor can put a game into a state its own save can't restore. A save made before editing is the undo.
