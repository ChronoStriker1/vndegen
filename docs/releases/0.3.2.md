Fixes Ren'Py games on Mac, which quit VNDegen in 0.3.0 and 0.3.1, and TyranoScript music and sound effects.

## Downloads

- `VNDegen-0.3.2-macOS.zip` for Mac (macOS 15 or later). It is ad-hoc signed: right-click VNDegen and choose Open the first time, or run `xattr -dr com.apple.quarantine /Applications/VNDegen.app`.
- `VNDegen-0.3.2.ipa` for iPhone and iPad (iOS 18 or later). Update it from the AltStore or SideStore source (`https://raw.githubusercontent.com/ChronoStriker1/vndegen/main/altstore/source.json`), or sideload it with Sideloadly. On iPhone and iPad, Ren'Py games are detected and listed but do not run yet.

## Fixed

- Ren'Py on Mac: pressing Play no longer quits VNDegen when its window isn't full screen. The library window now stays behind the game instead of being hidden, which macOS had treated as closing the app's last window.
- Ren'Py on Mac: with VNDegen full screen, the library comes back after you quit a game. Before, it stayed in its own Space and could only be reached by switching Spaces.
- TyranoScript: music no longer goes silent when a game restarts a track right after switching away from it.
- TyranoScript: games that set their audio with `setAttribute` now play Ogg music and sound effects on iPhone and iPad.
- TyranoScript: an audio load cancelled before it finished no longer blocks later audio, and queued or damaged audio files no longer use excess memory.
- TyranoScript: chained Ogg files play every stream, not only the first.

## Known limits

- Ren'Py on Mac: switching back to VNDegen with Cmd-Tab while a game runs in a window shows the library's Show game screen over the game. Show game returns to it. Moving the game window shows the library behind it.
- Changes to button mapping made while a Ren'Py game runs apply on its next launch.
- Opening the VNDegen menu from a Ren'Py game's main menu blanks that menu until you resume.
