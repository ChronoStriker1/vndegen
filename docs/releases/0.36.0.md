Artemis and Wolf RPG Editor games get a controller layout suggested from their own files, and a Wolf RPG key check that never fired is fixed.

## Downloads

- `VNDegen-0.36.0-macOS.zip` for Mac (macOS 15 or later). It is ad-hoc signed: right-click VNDegen and choose Open the first time, or run `xattr -dr com.apple.quarantine /Applications/VNDegen.app`.
- `VNDegen-0.36.0.ipa` for iPhone and iPad (iOS 18 or later). Update it from the AltStore or SideStore source (`https://raw.githubusercontent.com/ChronoStriker1/vndegen/main/altstore/source.json`), or sideload it with Sideloadly.

## New

- Suggested layouts for Artemis games. VNDegen reads the game's key table and puts auto mode, quick save, quick load, config, save, load and replay voice, in that order, on View, L3, R3 and LT, as far as they fit. Only what no button already does is added, so a game whose D-pad left and right already quick save and quick load gets auto, config, save and load. Each added button says what it does, such as "F2 key, Auto".
- Suggested layouts for Wolf RPG Editor games. Keys the game's events check, such as one that opens the message log, go on View, LT, L3 and R3, which did nothing in Wolf RPG games before.
- As with RPG Maker MV and MZ and Godot, the suggestion becomes the game's starting layout without asking and shows as "Suggested for this game" in the controller layout sheet. A, B, X, Y, LB, RB, RT, Menu, the D-pad and the sticks never change. Games already in your library get one too, and a game whose buttons you changed keeps them. [docs/controls.md](../controls.md) has the details.

## Fixes

- Wolf RPG Editor: a game's check for one specific key never passed, so the key did nothing (#86). This is why holding Control, on RT since 0.35.0, didn't skip messages in MilkyQuest. It does now. 0.35.0's notes said RT's Control skips in many Wolf RPG games; in games that check it this way it didn't until this release.
- AliceSoft System 4: Evenicle's game page now says it can't run yet, because it needs 3D before its title. It used to start and stop at once with an "unknown opcode" error (#84).

## Known limits

- Wolf RPG: a game's files say which key it checks but rarely what the key does, so most suggested buttons show only the key, such as "Q key". A few standard event names, such as the backlog and message skip, are labelled. Function keys aren't suggested. Of 10 games read, 6 got a suggestion.
- Artemis: of 6 games read, 3 got a suggestion. The other 3 are built on a script template that turns its shortcut keys off, so there is nothing to suggest.
- Artemis: a game whose own key config screen rebinds keys keeps the keys that were suggested.
- The touch gamepad has View and LT but no L3 or R3, so on a touch screen only the first two suggested keys can be pressed.
- NScripter games get no suggestion. In the 9 games read, every extra key does the same as a button the "Visual novel" layout already has.
- Evenicle doesn't run, and Rance IX still stops at its first battle or map. 3D for AliceSoft games isn't planned for now.
- Violated Hero was seen to stop partway through its opening (#85). Six later runs didn't reproduce it, so it is open and unfixed.

## What wasn't tested

- No physical device or hardware controller was used.
- Artemis: the four suggested buttons were pressed in one game, Fantasy Tavern Sextet Vol.1, on the iPad simulator. View and LT were pressed on the touch gamepad, and L3 and R3 through the app's test hooks. The layout sheet was looked at for that game in the Mac app.
- Wolf RPG: one suggested button, View opening the backlog, was pressed in one game, Journey of Depravity, on the iPad simulator's touch gamepad and in the Linux test build. Its LT key, which the game reads only in battle, wasn't pressed, and no game played had keys on L3 or R3.
- The #86 fix was seen in MilkyQuest and one other game in the Linux test build, not in the app. Drain Dungeon wasn't run.
- The other games' suggestions were made by the readers on Linux and not looked at in the app.
- Evenicle's page note was read from the engine on Linux, not looked at in the app.
- Not looked at on an iPhone.
- No code review was done on this release.
