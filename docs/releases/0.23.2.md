MalOvent now runs, the Mac's Controller layout sheet keeps one size, and a Wolf RPG Editor game kept inside an extra folder is found.

## Downloads

- `VNDegen-0.23.2-macOS.zip` for Mac (macOS 15 or later). It is ad-hoc signed: right-click VNDegen and choose Open the first time, or run `xattr -dr com.apple.quarantine /Applications/VNDegen.app`.
- `VNDegen-0.23.2.ipa` for iPhone and iPad (iOS 18 or later). Update it from the AltStore or SideStore source (`https://raw.githubusercontent.com/ChronoStriker1/vndegen/main/altstore/source.json`), or sideload it with Sideloadly.

## Fixes

- Ren'Py: MalOvent no longer stops with a TypeError when its main menu first draws. Games built for Ren'Py 8.3 or older can pass whole-number floats to `random.randrange` again.
- Ren'Py: opening VNDegen's menu no longer restarts a movie that keeps playing behind it, in a game that sets its movies up that way.
- Mac: the Controller layout sheet keeps one size through its steps, so buttons stay under the pointer, and each step opens at its focused item.
- Wolf RPG Editor, AliceSoft, and NScripter: a folder holding tied candidates gives the same answer at every launch.
- Wolf RPG Editor: a game three folders deep, inside an extra folder, is now found, such as Succubus Prison with its outer folder kept.

## Known limits

- Succubus Prison is found and starts, but it's stuck on its title screen for now, in issue 28. Its menu shows placeholder labels and doesn't start a game.
- Both Umineko Arcs are Ponscripter games, which VNDegen doesn't run, so they aren't detected, in issue 26.
- Looking for a Wolf RPG Editor game in extra folders lists each third-level folder once, up to 200, at each library refresh, for a folder with no other game found.

## What wasn't tested

- No physical device was used. The Mac sheet wasn't tried in a small window, and the Ren'Py and Wolf changes were tried on the Mac app and, for Ren'Py, an iPad simulator.
- Ren'Py on the Mac: the menu was opened by a key posted inside Ren'Py, not a real key press.
- Three archives couldn't be listed for the detection comparison: HENTAI EATER, Summer Clover, and プリンセスディフェンダー.
