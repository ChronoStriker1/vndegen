Fixes from testing the third survey's games: Princess and Conquest plays, and Wolf RPG Editor 3.3x saves load and save.

## Downloads

- `VNDegen-0.60.21-macOS.zip` for Mac (macOS 15 or later). It is ad-hoc signed: right-click VNDegen and choose Open the first time, or run `xattr -dr com.apple.quarantine /Applications/VNDegen.app`.
- `VNDegen-0.60.21.ipa` for iPhone and iPad (iOS 18 or later). Update it from the AltStore or SideStore source (`https://raw.githubusercontent.com/ChronoStriker1/vndegen/main/altstore/source.json`), or sideload it with Sideloadly.
- `VNDegen-0.60.21-LGPL-sources.tar`: the exact source of the LGPL libraries in this release. [docs/relinking.md](https://github.com/ChronoStriker1/vndegen/blob/main/docs/relinking.md) says how to replace one.





## Added

- **Wolf RPG Editor:** saves from Wolf RPG Editor 3.3x engines (save version 145, as False Myth 2 writes them) load and save, and move both ways with the PC game.

## Changed

- **Wolf RPG Editor:** a game that can't start because one of its archives can't be read now names the archive and the reason, instead of a missing file or no message at all.

## Fixed

- **RPG Maker MZ:** Princess and Conquest - Queen Of Clubs no longer goes black after New Game, and its portrait movies draw with their transparent parts see-through (#203). VNDegen's NW.js layer now has the `fs.openSync`, `readSync` and `closeSync` calls the game's movie plugin uses, and movies a game decrypts in memory get the same transparency conversion as movie files.

## Known limits

- **Princess and Conquest:** each portrait movie converts the first time it shows, so a character's first scene can take several seconds to appear (12 s on the iPhone simulator). Converted portraits are kept in the 512 MB movie cache, which holds the most recently played.
- **False Myth 2** (Wolf RPG Editor 3.343) doesn't start yet: its archives use a newer encryption VNDegen can't read. Its saves already work.

## What wasn't tested

- No physical device or physical controller was used. The Princess and Conquest fix was checked on iPad and iPhone simulators, with Milf Busters! (MZ) and Cornelica (MV) for other movies with transparency. The Mac app wasn't checked, since the test Mac's screen was locked.
- The Wolf saves were checked against the PC game under Wine, not by playing False Myth 2 in VNDegen, since it doesn't start yet.
- New test games that pass from import to a save and a load: The Royal Knight's Risk Hedge, Milf Busters! and Azure Steel Battle Princess Alvatia (RPG Maker MZ, on the iPad simulator), Bakana Imouto (VX Ace) and Heated Battle! Lewd Sports Day! (KiriKiri), in the Mac app.
- No code review was done on this release.
