Makes adding games work on installs where iOS will not hand picked files to VNDegen.

## Downloads

- `VNDegen-0.1.3.ipa` for iPhone and iPad (iOS 18 or later). Update it from the AltStore or SideStore source (`https://raw.githubusercontent.com/ChronoStriker1/vndegen/main/altstore/source.json`), or sideload it with Sideloadly.
- `VNDegen-0.1.3-macOS.zip` for Mac (macOS 15 or later). It is ad-hoc signed: right-click VNDegen and choose Open the first time, or run `xattr -dr com.apple.quarantine /Applications/VNDegen.app`.

## New

- Ready to import: copy a zip, RAR, or 7z into VNDegen's folder in the Files app (On My iPhone, VNDegen, or its Games folder), and the library lists it with an Import button. This needs no file picker, so it works even when Choose Archive does nothing. "Delete archive after import" starts on for these, since the archive was copied there only to import it.

## Fixed

- On some sideloaded installs, iOS refuses to give VNDegen access to a file picked in Choose Archive, opened with Open in VNDegen, or dropped from Files (the iPhone log shows `Could not resolve bookmark ... Cocoa 257`). Those paths could look like they do nothing. Ready to import avoids them.
- Archives are read under file coordination, so a cloud provider cannot move or replace one mid-import.
- Opening a second archive while the first is still being read no longer disturbs either one, and late or rejected drops no longer leave copies behind.
- Copies that arrive through Open in VNDegen are treated as copies: no delete toggle, and they are removed afterwards.

## Known limits

- Only RPG Maker MV and MZ games run so far.
- The Hidden games and Metadata sources settings pages still need touch or a mouse.
