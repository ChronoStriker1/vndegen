Three more YU-RIS games: Saimin Gakushū: Secret Desire, Kaizou Shoujo: Robokko to no Ichaicha Seikatsu! and Mamono Musume no Yakata: Ningyo no Sho.

## Downloads

- `VNDegen-0.40.0-macOS.zip` for Mac (macOS 15 or later). It is ad-hoc signed: right-click VNDegen and choose Open the first time, or run `xattr -dr com.apple.quarantine /Applications/VNDegen.app`.
- `VNDegen-0.40.0.ipa` for iPhone and iPad (iOS 18 or later). Update it from the AltStore or SideStore source (`https://raw.githubusercontent.com/ChronoStriker1/vndegen/main/altstore/source.json`), or sideload it with Sideloadly.

## New

- **Saimin Gakushū: Secret Desire** plays: its language picker, title, the story in English, choices, backlog, saving and loading. It is the first game on YU-RIS engine version 555, which reads its story from text files.
- **Kaizou Shoujo: Robokko to no Ichaicha Seikatsu!** and **Mamono Musume no Yakata: Ningyo no Sho** play, in Japanese: title, story, saving and loading. They are the first games on engine version 473.
- Saves of these games move to and from a PC, as for the other YU-RIS games.
- Eight YU-RIS games are now known to play. [docs/yuris.md](../yuris.md) lists them.

## Fixes

- YU-RIS: file, picture, sound and label names that hold certain Japanese characters are no longer mixed up with each other. In Saimin Gakushū one character drew wrong and a publisher logo didn't play.
- YU-RIS: a game whose save routine ends without the older closing command no longer leaks save records into its read-text file, which stopped the game with its own error on the next start.
- YU-RIS: a save made in VNDegen by a game on an engine older than 474 now loads in the PC engine, which crashed opening its load screen.

## Known limits

- Saimin Gakushū: a comment can't be typed on a save. Its Chinese text wasn't tried.
- Kaizou Shoujo's and Ningyo no Sho's ending movies weren't reached. They use the same decoder as the movies that were measured.
- Two library games on the oldest engine version (406), one whose text format changed (494) and one that looks like an unpacked copy haven't been tried.
- YU-RIS: YMV and Flash movies, MIDI, CD audio, E-mote, picture masks and a few picture effects aren't built, and a sound's pitch setting isn't applied.
- Violated Hero was seen to stop partway through its opening (#85). It hasn't been reproduced since and is still open.

## What wasn't tested

- No physical device or hardware controller was used.
- None of these games was run in the Mac app. The Mac mini's display was asleep and locked. What changed is in code the Mac app shares with the iPad simulator and the Linux test build.
- Saimin Gakushū was played in the Linux test build and on the iPad simulator, by touch and with the touch gamepad, with the case check there. Its brand movie ran at 29.9 frames a second against 30 on the iPad simulator.
- Kaizou Shoujo was played in the Linux test build, on a copy with every file name's case swapped, and on the iPad simulator. Ningyo no Sho was played in the Linux test build only.
- Saves were exchanged with the original engines under Wine in both directions for Saimin Gakushū and for Kaizou Shoujo.
- The fixes that touch every YU-RIS game were rechecked in the Linux test build with four of the earlier games, by loading a save and playing on.
- Not looked at on an iPhone.
- No code review was done on this release.
