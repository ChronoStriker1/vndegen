Groundwork for an App Store release: the iPhone and iPad app is about 3 MB smaller.

## Downloads

- `VNDegen-0.41.11-macOS.zip` for Mac (macOS 15 or later). It is ad-hoc signed: right-click VNDegen and choose Open the first time, or run `xattr -dr com.apple.quarantine /Applications/VNDegen.app`.
- `VNDegen-0.41.11.ipa` for iPhone and iPad (iOS 18 or later). Update it from the AltStore or SideStore source (`https://raw.githubusercontent.com/ChronoStriker1/vndegen/main/altstore/source.json`), or sideload it with Sideloadly.
- `VNDegen-0.41.11-LGPL-sources.tar`: the exact source of the LGPL libraries in this release. [docs/relinking.md](https://github.com/ChronoStriker1/vndegen/blob/main/docs/relinking.md) says how to replace one.

## Changes

- iPhone and iPad: MetalANGLE, which Ren'Py and Godot 3 draw through, now ships for 64-bit devices only, with the app's minimum iOS version, and signed. It was 10 MB larger, with code for 32-bit devices that iOS 18 can't run.
- iPhone, iPad and Mac: the app no longer carries an empty VPX framework. The WebM decoder for alpha movies was already inside the app.
- The IPA is 124.6 MB, down from 127.7 MB.

## What wasn't tested

- No physical device was used. A Ren'Py game, a Godot 3 game and an RPG Maker MZ alpha movie were checked on an iPad simulator, and the alpha movie in the Mac app.
- Apple's App Store validation, which needs a developer account.
- No code review was done on this release.
