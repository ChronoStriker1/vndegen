Fixes for save sync on a large or slow server, and three engine fixes left over from the code review.

## Downloads

- `VNDegen-0.41.5-macOS.zip` for Mac (macOS 15 or later). It is ad-hoc signed: right-click VNDegen and choose Open the first time, or run `xattr -dr com.apple.quarantine /Applications/VNDegen.app`.
- `VNDegen-0.41.5.ipa` for iPhone and iPad (iOS 18 or later). Update it from the AltStore or SideStore source (`https://raw.githubusercontent.com/ChronoStriker1/vndegen/main/altstore/source.json`), or sideload it with Sideloadly.

## Fixes

Save sync:
- Save sync no longer slows the app's start with a large Ludusavi store: it reads its copy of the store in the background (#104).
- A backup or restore over a slow connection is no longer cut off after 3 minutes. It continues while data is moving, and gives up only when nothing has moved for a minute (#104).

Engines:
- YU-RIS: a number too large for an integer now converts as it does on the PC, instead of giving an undefined result (#171).
- System 4: save slot details are written whole, so a failed write keeps the old ones (#173).
- KiriKiri: a small image the engine kept for the whole session is now freed when a game ends (#174).

## Known limits

- A server that keeps sending data very slowly can now hold up save sync for as long as it keeps sending.
- A Rance 02 resume save made at Camp may not load in a new session (#175). This is older than this release and is being looked at.
- KiriKiri still keeps some of a game's objects after it ends, about 14 MB per game played in one session (#176).

## What wasn't tested

- No physical device was used. Checks were the package tests, the Mac and iOS builds, and Linux test hosts with memory and undefined-behavior checking.
- Save sync was tried in the Mac app against a local WebDAV server with 300 games. The one-minute limit was tested against a local store only, not real SMB, FTP or WebDAV servers or a slow network.
- The YU-RIS, System 4 and KiriKiri fixes were run with real games outside the app (Tales of the Yokai Incident Inspectors, Rance 02, and KiriKiri restarts), not in the Mac app.
- No iPhone or iPad simulator was used, since nothing changed input or layout.
- No code review was done on this release.
