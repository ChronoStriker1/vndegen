You can now remove the PC engine files a game doesn't need in VNDegen, which saves about 88 to 295 MB a game on average for RPG Maker MV and MZ, TyranoScript, and Ren'Py.

## Downloads

- `VNDegen-0.22.0-macOS.zip` for Mac (macOS 15 or later). It is ad-hoc signed: right-click VNDegen and choose Open the first time, or run `xattr -dr com.apple.quarantine /Applications/VNDegen.app`.
- `VNDegen-0.22.0.ipa` for iPhone and iPad (iOS 18 or later). Update it from the AltStore or SideStore source (`https://raw.githubusercontent.com/ChronoStriker1/vndegen/main/altstore/source.json`), or sideload it with Sideloadly.

## New: Remove engine files

- Remove engine files is on a game's page and in its long press or right-click menu. An archive you import asks once, when the game it adds has any to remove.
- It lists the files and the space you'd save, and removes nothing until you confirm. The game keeps running in VNDegen, but it won't run on a PC from that folder afterwards.
- Each engine lists exactly what it may remove, and anything else stays, including saves and the game's own data. A mod's program, Python, or certificate file inside a Ren'Py `lib/` folder is the one exception, because VNDegen can't tell it from the engine's own.
- Other engines don't offer it.

Average saved per game, measured across one library:

| Engine | Average saved |
|---|---|
| RPG Maker MZ | 295 MB |
| TyranoScript | 183 MB |
| RPG Maker MV | 148 MB |
| Ren'Py | 88 MB |

Where the files go depends on where the game is:

- On a Mac, they go to the Trash, and the space comes back when you empty it.
- On iPhone and iPad, they are deleted for good.
- In iCloud Drive, the removal reaches every device on that iCloud account. iCloud Drive's Recently Deleted should keep the files for about 30 days.

VNDegen shows the reason and removes nothing for a network share, a read-only folder, or a cloud service other than iCloud Drive. On iPhone and iPad this also covers folders added from On My iPhone or iPad outside VNDegen's own folder, because VNDegen can't tell those from another provider's. VNDegen's own Games folder works.

## What wasn't tested

- iCloud Drive hasn't been tested at all, including removal, files not downloaded yet, and restoring from Recently Deleted. Try it first on a game you don't mind adding again.
- Restoring from the Mac Trash isn't confirmed. Finder offered Put Back for only some of the files, and a scripted move back from the Trash stalled, for a reason not yet known.
- Real network shares, read-only folders, and other cloud services are covered by unit tests only.
- No physical iPhone or iPad was used. Checks ran on the iPad simulator and the Mac app, on copies of games. Not every engine's save and load was checked: Konpoko (RPG Maker MV) and Butterfly (TyranoScript with NW.js) got no slot save and load, though other games on those engines did.

## Known limits

- Desktop and Documents folders synced to iCloud are refused as cloud storage.
- A shared iCloud folder counts as ordinary iCloud, so a removal there would also reach the people it's shared with.
- An `.exe` under 250 MB that holds more of the game than its loose files is treated as the engine's own. No library game does this.
- The Cheats page can fail to load in No Socks RPG, with "Couldn't read the game" (issue #9). A fix is in progress.
