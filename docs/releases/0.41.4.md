A large round of fixes from a review of the whole codebase: crashes from damaged or crafted game files, a library that could lose its data, freezes, and slow spots.

## Downloads

- `VNDegen-0.41.4-macOS.zip` for Mac (macOS 15 or later). It is ad-hoc signed: right-click VNDegen and choose Open the first time, or run `xattr -dr com.apple.quarantine /Applications/VNDegen.app`.
- `VNDegen-0.41.4.ipa` for iPhone and iPad (iOS 18 or later). Update it from the AltStore or SideStore source (`https://raw.githubusercontent.com/ChronoStriker1/vndegen/main/altstore/source.json`), or sideload it with Sideloadly.

## Fixes

Library, lock and save sync:
- The library no longer loses everything when one game's record can't be read, as could happen after installing an older release. A file that isn't readable is set aside, never saved over.
- Hidden games can no longer be opened by setting a new passcode when Touch ID, Face ID or the Keychain is unavailable. Wrong passcodes wait longer each time, also after a relaunch.
- A game folder renamed only in case keeps its record, art and play time.
- Library saves no longer stall the screen, and returning to the app no longer rescans the library or searches metadata again each time.
- Native engines' sound comes back after an audio device change.
- Save sync no longer crashes on a mapping that lists a file twice, and no longer records a save twice when names differ in case.
- A `.zip` that is really a 7z archive extracts. Nested installers no longer freeze the import screen, and crafted installers can't crash the app.

Web games, Flash, Artemis and movies:
- One unreadable save value no longer breaks a web game's input and saves.
- A page or Twine passage that embeds a web frame no longer opens Safari.
- Twine and Harlowe alert, confirm and prompt boxes now show.
- Hover effects work with the controller and the Cursor-mode pointer.
- A page that keeps crashing ends with a message instead of reloading forever.
- Transparent RPG Maker movies no longer hold up other videos while one converts, and transparent WebMs without a duration now convert.
- Flash saves are found when a launcher names the movie in a different case.
- Artemis script links open only web pages, and only after asking.
- NekoSDK movie sound no longer stutters while a frame decodes, and a damaged movie's sound gap no longer freezes it.
- Crafted MPEG-1 movies can no longer corrupt memory, and a movie with a zero frame rate ends.

RPG Maker XP, VX, VX Ace and Wolf RPG Editor:
- Fixed crashes from sound files with more than 8 channels, damaged fonts, huge drawing coordinates, and bad Table sizes or tile IDs.
- Faster window and plane drawing.
- Games that make their own save folder, or use other file calls, now work.
- XP and VX: variables with Japanese names survive saves.
- XP: Change Level no longer jumps when the experience cheat is on.
- Wolf RPG Editor: a failed save no longer replaces the good one, image memory is bounded, and runaway sizes from event commands no longer crash the app.

System 4 and YU-RIS:
- Damaged or hand-edited archives, scripts and saves no longer crash the app or use up its memory.
- System 4 keeps the old save when a write fails, and finds save files whatever their case, also in game folders with accented names.
- YU-RIS text keeps the right font after several fonts or games in one session.
- Faster ALD archive opening and opaque sprite drawing.

KiriKiri, NScripter, System 3 and NekoSDK:
- KiriKiri reads a game's `.cf` and `.cfu` files whatever their case, gives each game its own fonts when several are played in one session, says why a game couldn't start, and survives damaged XP3 indexes.
- KiriKiri text split on non-ASCII characters is split correctly (#92).
- NekoSDK no longer crashes or freezes on damaged choices, blurs or saves, keeps a damaged `cfg.sav` or `read.sav` instead of overwriting it, and never writes saves outside the game's data folder.
- NekoSDK: Auto mode waits as long as the PC does in six more games, and one game's submenus and message window now behave as on the PC.
- NScripter's Lua no longer loads precompiled code, and a runaway Lua function stops after 5 seconds instead of freezing the app.
- Damaged images and scripts in NScripter and System 3 games no longer crash the app or use up its memory. System 3 games use less memory.

Godot:
- A frame-capped game no longer freezes VNDegen when started after another capped game, and no longer slows VNDegen's menus and touch controls.
- Games that leave threads running at quit no longer crash VNDegen. A game whose files fail to load no longer stops other Godot games until VNDegen is reopened.
- Physics interpolation works in every game of a session, and Godot games in large packs are found faster.

Other:
- Faster case-insensitive file lookups for RGSS, System 3, Wolf RPG Editor, YU-RIS and KiriKiri.
- Library detection picks the shallowest game folder every time.

## Known limits

- A Godot game whose background work never stops at quit leaves Godot unusable until VNDegen is reopened, and quitting VNDegen afterwards may show a crash report.
- System 4 still writes save slot details in place, so a failed write can leave them unreadable (#173).
- Some review items are only partly done and stay open: #104, #109, #121, #164, #166 and #169.

## What wasn't tested

- No physical device or hardware controller was used. Checks were the package tests, the Mac and iOS builds, Linux test hosts with memory checking, and short runs of one or more games per engine in the Mac app.
- A real audio device change, the Touch ID fallback on a MacBook with its lid closed, and a real Twine game's alert boxes weren't tried.
- Starting one frame-capped Godot game after another was tested on Linux only.
- KiriKiri's `.cf` case handling was compiled but not run on a case-sensitive disk. NekoSDK save writing was tested by the package tests, not in the app.
- No iPhone or iPad simulator was used for these fixes, since none changed input or layout.
- No code review was done on this release.
