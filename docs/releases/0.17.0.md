Adds cheats for AliceSoft System 3 and 4 games and a find-by-value search on every game's Variables tab, and fixes Las Gorditas 2 starting on a black screen.

## Downloads

- `VNDegen-0.17.0-macOS.zip` for Mac (macOS 15 or later). It is ad-hoc signed: right-click VNDegen and choose Open the first time, or run `xattr -dr com.apple.quarantine /Applications/VNDegen.app`.
- `VNDegen-0.17.0.ipa` for iPhone and iPad (iOS 18 or later). Update it from the AltStore or SideStore source (`https://raw.githubusercontent.com/ChronoStriker1/vndegen/main/altstore/source.json`), or sideload it with Sideloadly.

## New: cheats for AliceSoft System 3 and 4

- AliceSoft System 3 and 4 games get the Cheats page: a Variables tab and 2x or 4x game speed. Rance 02 and Sengoku Rance also get gold on the Quick tab.
- Saves made afterwards are the games' ordinary saves.
- Movies keep normal speed while the game runs faster, so their pictures stay with their sound.

## New: find a value

- Every game's Variables tab can find a value. Type a number the game shows, such as your gold, and the list keeps only the variables holding it. After the number changes in the game, find the new value to narrow the list to one.

## Fixes

- TyranoScript: Las Gorditas 2 and other Electron builds made with TyranoScript 5.2 or later no longer stop on a black screen at startup.

## Known limits

- AliceSoft System 3 games have no gold on the Quick tab. Find a value finds it on the Variables tab.
- A yes-or-no variable in System 4 takes only 0 or 1.
- The cheats' variable editor can put a game into a state its own save can't restore. A save made before editing is the undo.
