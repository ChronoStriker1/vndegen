Control methods and button mapping, from testing on a real iPhone.

## Downloads

- `VNDegen-0.2.1.ipa` for iPhone and iPad (iOS 18 or later). Update it from the AltStore or SideStore source (`https://raw.githubusercontent.com/ChronoStriker1/vndegen/main/altstore/source.json`), or sideload it with Sideloadly.
- `VNDegen-0.2.1-macOS.zip` for Mac (macOS 15 or later). It is ad-hoc signed: right-click VNDegen and choose Open the first time, or run `xattr -dr com.apple.quarantine /Applications/VNDegen.app`.

## New

- Control method per game: Automatic (overlay unless a controller is connected), Touch gamepad, Touch mouse, or Controller only with no overlay. Set it on the game's page, set the default in Settings, or switch it while playing from the VNDegen menu.
- Button mapping per game: any overlay button or controller button can send a gamepad action, a keyboard key, a click, or nothing. Edit it from the game's page or the VNDegen menu, by touch or controller. A remapped overlay button shows its key. Options, Home, and the backtick always open the VNDegen menu.

## Fixed

- The Import button on Ready to import no longer wraps onto two lines.
- The doubled button in the top-right corner while playing is gone. The overlay's Home button opens the VNDegen menu; with no overlay, one small corner button does.

## Known limits

- A very quick tap on a remapped button can be missed by RPG Maker games, which read keys once per frame. A normal press works.
- If you had picked Mouse or Hidden under the old "Touch controls" setting, pick the control method again.
- The right stick cannot be mapped yet.
