Adds Flash games on Mac, iPhone and iPad, played by Ruffle, a Flash Player written in Rust. Games now find their files whatever case they name them in, Windows fonts get free substitutes with the same metrics, and VNDegen fits small and odd iPad windows.

## Downloads

- `VNDegen-0.7.0-macOS.zip` for Mac (macOS 15 or later). It is ad-hoc signed: right-click VNDegen and choose Open the first time, or run `xattr -dr com.apple.quarantine /Applications/VNDegen.app`.
- `VNDegen-0.7.0.ipa` for iPhone and iPad (iOS 18 or later). Update it from the AltStore or SideStore source (`https://raw.githubusercontent.com/ChronoStriker1/vndegen/main/altstore/source.json`), or sideload it with Sideloadly.

## New

- Flash games run inside VNDegen's window. VNDegen finds a Windows projector (`Game.exe` with the movie inside), a `.swf` movie, or a collection's own HTML menu page, up to four folders down, and plays the projector's movie without unpacking it. A game's page offers its other movies under Start with, such as a loader or gallery unlock that ships beside the game.
- Flash games written in ActionScript 1, 2 and 3 work, drawn with WebGL on Metal.
- Flash saves are Flash's own `.sol` files, kept in the game's data folder by the movie that made them, and Ludusavi backups map them to and from Flash Player and Ruffle on a PC. The game writes them when it pauses, when VNDegen leaves the screen, and when it quits.
- In Flash games, the VNDegen menu, the touch gamepad, touch mouse, controllers and the keyboard all work. Flash games start with the Keyboard and mouse layout. A projector's Exit button returns to the library.
- Windows fonts. Games that ask for MS Gothic, MS Mincho, Arial, Tahoma and other Windows fonts by name get free fonts with the same metrics, as under Proton: Ume fonts for the Japanese ones, Liberation for Arial, Times New Roman and Courier New, and DejaVu for Tahoma. RPG Maker MV and MZ, TyranoScript, KiriKiri, RPG Maker XP, VX and VX Ace, and Flash games use them. Chinese and Korean substitutes are a download in Settings, Fonts. KiriKiri games without a default font of their own now use the MS PGothic substitute, as on Windows.
- iPad windows. VNDegen fits small and odd window sizes on iPad. The library, game pages, the in-game menu, the touch gamepad and every engine fit the window and stay clear of iPadOS's window controls. A game in a window follows the window's shape.

## Fixed

- Every engine finds a game's files and folders whatever case the game uses, as on Windows, on iPhone, iPad and case-sensitive Mac volumes. Before, a game that asked for `Img/Title.PNG` when the disk had `img/title.png` failed there. Saving to a name that exists in another case replaces that file instead of making a second copy.

## Known limits

- Ruffle's ActionScript 3 support is less complete than for ActionScript 1 and 2, so some AS3 games may stop or skip something. One test game needed a fix to Ruffle, which VNDegen includes.
- Flash microphone input doesn't exist.
- A Flash collection's HTML menu keeps the layout it had in a desktop browser.
- Tested with the 14 Flash games in the library. All reach their title and play on the Mac and the iPad simulator, and the 12 that save also save and load. One plays on the iPhone simulator.
- The iPad window layouts were checked on the iPad simulator at sizes down to 320 points wide and in real windows. Drag-resizing, tiling and Slide Over couldn't be driven in the simulator.
- The Chinese and Korean font downloads are 51 MB and 26 MB.
