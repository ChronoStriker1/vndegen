Two more YU-RIS games: Mamono Musume-tachi to no Rakuen: Slime & Scylla and Saint Dorei Gakuen 2.

## Downloads

- `VNDegen-0.41.0-macOS.zip` for Mac (macOS 15 or later). It is ad-hoc signed: right-click VNDegen and choose Open the first time, or run `xattr -dr com.apple.quarantine /Applications/VNDegen.app`.
- `VNDegen-0.41.0.ipa` for iPhone and iPad (iOS 18 or later). Update it from the AltStore or SideStore source (`https://raw.githubusercontent.com/ChronoStriker1/vndegen/main/altstore/source.json`), or sideload it with Sideloadly.

## New

- **Mamono Musume-tachi to no Rakuen: Slime & Scylla** plays, in Japanese: title, story, choices, saving and loading. It is the first game on YU-RIS engine version 406, the oldest in the test library.
- **Saint Dorei Gakuen 2** plays, in English: title, story, backlog, saving and loading. It is the first game on engine version 479 and the first with YCG pictures.
- An English patch installed as loose files in a YU-RIS game's folder is used, as on the PC: a loose file replaces the archive entry of the same name.
- Saves of both games move to and from a PC.
- Nine YU-RIS games are now known to play. [docs/yuris.md](../yuris.md) lists them.

## Fixes

- YU-RIS: a button whose hit area is a fully transparent picture now takes clicks, as on the PC. In Saint Dorei Gakuen 2 the save slots did nothing.

## Known limits

- Saint Dorei Gakuen 2's scripts name an opening and an ending movie that the tested copy doesn't contain, so they were never played.
- Saimin Gakushū: a comment can't be typed on a save.
- YU-RIS: YMV and Flash movies, MIDI, CD audio, E-mote, picture masks and a few picture effects aren't built, and a sound's pitch setting isn't applied.
- Six YU-RIS games in the test library weren't tested, one of them on engine version 494, whose text format the runtime doesn't read yet.
- Violated Hero was seen to stop partway through its opening (#85). It hasn't been reproduced since and is still open.

## What wasn't tested

- No physical device or hardware controller was used.
- Neither game was run in the Mac app. The Mac mini's display was asleep and locked. What changed is in code the Mac app shares with the iPad simulator and the Linux test build.
- Slime & Scylla was played in the Linux test build only. Saint Dorei Gakuen 2 was played in the Linux test build, on a copy with every file name's case swapped, and on the iPad simulator by touch and with the touch gamepad.
- Saves were exchanged with the original engines under Wine in both directions for both games.
- The transparent-picture fix touches every YU-RIS game's buttons. All nine games were rechecked in the Linux test build by loading a save and playing on.
- No movie was measured in this release.
- Not looked at on an iPhone.
- No code review was done on this release.
