RPG Maker MV and MZ games now show their see-through video clips correctly, and MV games recover when the system reclaims their graphics.

## Downloads

- `VNDegen-0.21.0-macOS.zip` for Mac (macOS 15 or later). It is ad-hoc signed: right-click VNDegen and choose Open the first time, or run `xattr -dr com.apple.quarantine /Applications/VNDegen.app`.
- `VNDegen-0.21.0.ipa` for iPhone and iPad (iOS 18 or later). Update it from the AltStore or SideStore source (`https://raw.githubusercontent.com/ChronoStriker1/vndegen/main/altstore/source.json`), or sideload it with Sideloadly.

## New: see-through video clips

- RPG Maker MV and MZ clips with transparency no longer show a black or white box. The first time a clip plays, VNDegen converts it in the background to a format Apple's system can play with transparency. It keeps the result in a cache outside the game folder and uses it from then on. Game files and saves don't change.
- This covers both engines and the movie plugins library games use, such as in Cornelica, Holding Hands, Fallen Kunoichi and No Socks RPG.
- A clip stays hidden until it's ready, so the first play of a clip can wait while it converts, and uses more battery and memory. Later plays start straight away.
- The cache holds up to 512 MB, dropping the clips used least recently. Settings has a Clear video cache button.

## Fixes

- RPG Maker MV: games on PIXI 4 recover from a lost graphics context instead of going black, which iOS can cause when it runs short of memory.
- RPG Maker MZ: game speed no longer drops a heavy game to half its frame rate, though such a game may run a little below the chosen speed. No Socks RPG at 4x went from 23 to about 39 frames a second on the iPad simulator.
- Mac: the numeric keypad's digits and Enter now work in games.

## Known limits

- Converting a clip can add a lot of memory while it runs: about 160 MB on a Mac, and up to about 390 MB on an iPad simulator. Real iPad speed and memory haven't been measured. If a game closes while a clip converts, please report it.
- RPG Maker: Karryn's Prison doesn't start yet. A fix is in progress.
- RPG Maker MV: The Midsummer Night's Sabbat and Queena's Legend stay black after losing their graphics until they're restarted.
- RPG Maker: `siru.webm` in Trinity Dungeon, under 64 pixels wide, was checked only by file scan. Clips with VP8 or VP9 profile 2 or 3 alpha aren't converted. No library game has them.
