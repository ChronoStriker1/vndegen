Rance 02 resume saves load again, and two KiriKiri fixes.

## Downloads

- `VNDegen-0.41.6-macOS.zip` for Mac (macOS 15 or later). It is ad-hoc signed: right-click VNDegen and choose Open the first time, or run `xattr -dr com.apple.quarantine /Applications/VNDegen.app`.
- `VNDegen-0.41.6.ipa` for iPhone and iPad (iOS 18 or later). Update it from the AltStore or SideStore source (`https://raw.githubusercontent.com/ChronoStriker1/vndegen/main/altstore/source.json`), or sideload it with Sideloadly.

## Fixes

- System 4: Rance 02 resume saves load again (#175). An engine bug damaged every resume save the game made. Resume saves made with earlier versions can't be recovered.
- KiriKiri: a game that reads a pixel's color gets red and blue in the right order (#177).
- KiriKiri: playing several games in one session no longer keeps each finished game's images in memory (#176).

## What wasn't tested

- No physical device was used. Checks were the package tests, the Mac and iOS builds, and runs outside the app with memory checking: Rance 02 saving and loading a resume, a Sengoku Rance start, and several KiriKiri games in one session.
- These fixes were not run in the Mac app or on an iPhone or iPad simulator.
- No code review was done on this release.
