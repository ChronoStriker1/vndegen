Ludusavi backups keep a Windows PC's registry data, Wolf RPG Editor message windows draw like the PC's, and Violated Hero IV (Partial E) is found.

## Downloads

- `VNDegen-0.24.1-macOS.zip` for Mac (macOS 15 or later). It is ad-hoc signed: right-click VNDegen and choose Open the first time, or run `xattr -dr com.apple.quarantine /Applications/VNDegen.app`.
- `VNDegen-0.24.1.ipa` for iPhone and iPad (iOS 18 or later). Update it from the AltStore or SideStore source (`https://raw.githubusercontent.com/ChronoStriker1/vndegen/main/altstore/source.json`), or sideload it with Sideloadly.

## Fixes

- Ludusavi: a backup VNDegen writes now keeps the registry data a Windows PC's backup holds, so Ludusavi on the PC can still restore it. Before, it was marked as dropped and then lost once old backups were pruned. No engine VNDegen runs keeps saves in the registry, so this only protects what a PC put there.
- Wolf RPG Editor: message windows no longer show a faint second edge, as in Succubus Prison and Drain Dungeon. The game's own window and portraits show as on the PC, and VNDegen draws only the text.
- KiriKiri: Violated Hero IV (Partial E) is found inside its three wrapper folders.

## Known limits

- VNDegen doesn't restore registry data on a Mac, iPhone, or iPad. It only carries it forward in the backup.
- Wolf RPG Editor: a game that never sets where its message text goes, loaded from an old save, shows its text at the top left.

## What wasn't tested

- No physical device was used. A Windows registry restore from a VNDegen backup wasn't tried. Ludusavi 0.31.0 on Linux read VNDegen's backups.
- The Wolf change was checked in the Mac app and on Linux, and compared with the PC engine under Wine for two games. An iPhone or iPad simulator wasn't run for it.
