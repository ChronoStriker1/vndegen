Fixes from the independent code review. No new features.

## Downloads

- `VNDegen-0.1.1.ipa` for iPhone and iPad (iOS 18 or later). Install or update it from the AltStore or SideStore source (`https://raw.githubusercontent.com/ChronoStriker1/vndegen/main/altstore/source.json`), or sideload it with Sideloadly.
- `VNDegen-0.1.1-macOS.zip` for Mac (macOS 15 or later). It is ad-hoc signed: right-click VNDegen and choose Open the first time, or run `xattr -dr com.apple.quarantine /Applications/VNDegen.app`.

## Fixed

- "Delete archive after import" is offered only for archives stored inside VNDegen itself, so it can no longer remove the original of a file synced by iCloud, Dropbox, or OneDrive.
- Archive import enforces size and free-space limits while it writes, rejects archives that declare impossible sizes, and no longer crashes on a malformed multi-part RAR name.
- Cancelling at the very end of an import can no longer finish it or delete the archive.
- On Mac, quitting mid-game always completes within about 20 seconds, even if a save backup hangs.
- A controller can now reach the folder name and password fields when importing, and focus no longer lands on a hidden row in the Ludusavi folder picker.

## Known limits

- Only RPG Maker MV and MZ games run so far.
- The Hidden games and Metadata sources settings pages still need touch or a mouse.
