Add game now unpacks a game from its GOG installer or from an ISO disc image, without running the installer.

## Downloads

- `VNDegen-0.37.0-macOS.zip` for Mac (macOS 15 or later). It is ad-hoc signed: right-click VNDegen and choose Open the first time, or run `xattr -dr com.apple.quarantine /Applications/VNDegen.app`.
- `VNDegen-0.37.0.ipa` for iPhone and iPad (iOS 18 or later). Update it from the AltStore or SideStore source (`https://raw.githubusercontent.com/ChronoStriker1/vndegen/main/altstore/source.json`), or sideload it with Sideloadly.

## New

- GOG installers. Add game unpacks a game from its GOG installer, the `setup_<game>_(<number>).exe` with any `-1.bin`, `-2.bin` parts, without running it. VNDegen reads the installer like an archive and keeps only the game's files. Choose the `.exe`, drop it, open it in VNDegen, or copy it into VNDegen's folder to see it under Ready to import.
- Add-ons. A GOG add-on, such as an "unrated" installer, that sits beside the main installer or is chosen with it goes into the same game folder. "Include" with the add-on's name is on by default and can be turned off. An add-on chosen on its own is refused with a message to choose it together with the main installer.
- Installers inside archives. An archive that holds only an installer offers to unpack the game from it.
- ISO disc images import like archives. A disc that holds its game as plain files becomes a game folder.
- The game folder is named after the game's GOG title, and a multi-language installer unpacks the device's language when it has it, otherwise the installer's default.
- "Delete installer after import" works as it does for archives: it is offered for installers in VNDegen's own folders and deletes every part of each installer that was unpacked.
- [docs/library.md](../library.md#installers-and-disc-images) has the details.

## Known limits

- Only Inno Setup 5 installers, which is what GOG's installers for these games are. Inno Setup 6, NSIS, InstallShield, MSI and Setup Factory installers, repacked installers, password-protected installers, and BIN/CUE, MDF/MDS or UDF-only disc images are refused with a message saying so.
- On an iPhone or iPad, an installer outside VNDegen's own folder needs its `.exe` and every `.bin` chosen together.
- An add-on can't yet be added to a game already in the library.
- Installer helpers, the uninstaller, GOG's support files and redistributables such as DirectX are left out, and nothing is written to a registry.
- Violated Hero was seen to stop partway through its opening (#85). It hasn't been reproduced since and is still open.

## What wasn't tested

- No physical device was used.
- Three games were added in the app and started: a GOG installer with its add-on (a KiriKiri game, to its title) and an ISO inside a zip (an NScripter game, into its opening) in the Mac app, and a GOG installer with its add-on inside a RAR (a Wolf RPG game, to its title) on the iPad simulator. All three went through Ready to import. The picker, drag and drop, and Open in VNDegen were not tried with an installer in the app.
- Six real installers were unpacked on Linux and matched a reference unpacker file for file. The other GOG installers in the test library had only their headers read.
- The last wording changes in the import sheet (the installer's name, the delete switch's label, the list of installers in the archive prompt and the empty library's help text) were built but not looked at in the app.
- Cancelling while an installer unpacks wasn't tried in the app. It uses the same code as cancelling an archive.
- A multi-language installer and the 64-bit choice were tested with made-up installers in the unit tests only.
- Not looked at on an iPhone.
- No code review was done on this release.
