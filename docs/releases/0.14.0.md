Adds more than one library folder, a menu on each game in the library, Game commands for menus VNDegen didn't show, and cheats for RPG Maker MV and MZ games.

## Downloads

- `VNDegen-0.14.0-macOS.zip` for Mac (macOS 15 or later). It is ad-hoc signed: right-click VNDegen and choose Open the first time, or run `xattr -dr com.apple.quarantine /Applications/VNDegen.app`.
- `VNDegen-0.14.0.ipa` for iPhone and iPad (iOS 18 or later). Update it from the AltStore or SideStore source (`https://raw.githubusercontent.com/ChronoStriker1/vndegen/main/altstore/source.json`), or sideload it with Sideloadly.

## New: library folders

- Settings > Library folders adds more folders of games, such as a folder on an external drive, a server in Files, or another folder on the Mac. The built-in folder stays.
- A folder that can't be reached keeps its games in the library, shown as unavailable with the reason, until it's back. Removing a folder takes its games out of the library and leaves the files alone.
- Add game asks which folder to unpack an archive into.
- Libraries from earlier versions open with every game, its artwork, metadata, play time and settings.

## New: a menu on each game in the library

- A long press on a game in any library layout, a right click on the Mac, or X on a controller opens Play, Open game page, Change artwork, Find metadata, Hide, Show in Finder or Open in Files, and Remove from library.
- Remove from library deletes the game's folder after asking: to the Trash on a Mac, for good on iPhone and iPad. The saves VNDegen keeps for the game in its own data folder stay, and so do its artwork, play time and settings.

## New: Game commands

- VNDegen's in-game menu has a Game commands entry that lists commands a game keeps where VNDegen draws nothing, and runs them in the game:
  - a KiriKiri game's window menu bar, so games such as Tawawa Oku-san x Happening Gym get their Quick Save, Quick Load, Save, Load, Backlog, Auto and Skip back;
  - an NScripter game's menu bar, such as Lilipalace's Skip and Text Speed;
  - a Flash movie's own right-click items, through a patched Ruffle;
  - Auto and Skip in RPG Maker MV games that use the MessageSkip plugin;
  - Quick save and Quick load for Ren'Py games on iPhone and iPad.
- KiriKiri games are told their menu bar is visible unless their scripts check for a hidden one. The game page's Window menu option overrides this per game.

## New: cheats for RPG Maker MV and MZ

- A Cheats page in the VNDegen menu adds gold and items from the game's own database and restores the party.
- Settings that stay on, per game: keep HP and MP full, no random encounters, walk through walls, 2x or 4x game speed, and an experience multiplier. The game page shows when a game has cheats on.
- The Variables and Switches tabs list the game's variables and switches by name for editing.
- Every change goes through the game's own objects, so saves made afterwards are ordinary PC saves.

## Settings

- Settings > Plugins lists every engine plugin with the versions it covers, what runs it, its license, how many of your games use it, and whether it runs on this device.

## Fixes

- RPG Maker MV games on the community core, such as Rookie Knight Rathi, save to `www/save/` like the PC version. Saves an earlier VNDegen wrote to `save/` move there on the game's first launch and appear in its save list.
- Early RPG Maker MV games such as The Midsummer Night's Sabbat, which couldn't save, now save to `save/` like the PC version.

## Known limits

- On the Mac, the right click on a game and the folder picker in Settings weren't checked in the test runs. The same menu was tested on iPhone and iPad.
- External drives and network shares weren't tested. A folder that couldn't be read stood in for one that's offline.
- No Socks RPG at 4x speed draws about 24 frames a second, while its game runs about 3.2 times as fast.
- Not every Taimanin Kurenai Display menu item does something in VNDegen.
- An NScripter menu-bar text speed lasts only until the game quits.
