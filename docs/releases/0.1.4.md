Safety fixes for importing archives.

## Downloads

- `VNDegen-0.1.4.ipa` for iPhone and iPad (iOS 18 or later). Update it from the AltStore or SideStore source (`https://raw.githubusercontent.com/ChronoStriker1/vndegen/main/altstore/source.json`), or sideload it with Sideloadly.
- `VNDegen-0.1.4-macOS.zip` for Mac (macOS 15 or later). It is ad-hoc signed: right-click VNDegen and choose Open the first time, or run `xattr -dr com.apple.quarantine /Applications/VNDegen.app`.

## Fixed

- "Delete archive after import" now deletes an archive only if it is still the same file VNDegen imported. If you replace it in Files during an import, the new file is kept and the result screen says so.
- Copies delivered through Open in VNDegen are no longer cleaned up while an import is still reading them or before VNDegen has received them.
- Split archives with the same name in different formats (for example `Game.zip.001` and `Game.7z.001`) are listed as separate archives, and two files for the same part are refused with a clear message.

## Known limits

- Only RPG Maker MV and MZ games run so far.
- The Hidden games and Metadata sources settings pages still need touch or a mouse.
