The libraries under the LGPL can now be replaced by the user, and fixes for RPG Maker VX Ace and AliceSoft System 4.

## Downloads

- `VNDegen-0.41.9-macOS.zip` for Mac (macOS 15 or later). It is ad-hoc signed: right-click VNDegen and choose Open the first time, or run `xattr -dr com.apple.quarantine /Applications/VNDegen.app`.
- `VNDegen-0.41.9.ipa` for iPhone and iPad (iOS 18 or later). Update it from the AltStore or SideStore source (`https://raw.githubusercontent.com/ChronoStriker1/vndegen/main/altstore/source.json`), or sideload it with Sideloadly.
- `VNDegen-0.41.9-LGPL-sources.tar`: the exact source of the LGPL libraries in this release. [docs/relinking.md](https://github.com/ChronoStriker1/vndegen/blob/main/docs/relinking.md) says how to replace one.

## Licenses

- FFmpeg, which KiriKiri and NekoSDK use for movies, is now a framework of its own in the app. On iPhone and iPad, so are Ren'Py's libraries. Each can be replaced with your own build.
- SMB save sync no longer contains an unused LGPL-3 module; VNDegen's own MIT code takes its place.
- The iPhone and iPad download is 1.3 MB larger, and the Mac download 0.6 MB larger.

## Fixes

- RPG Maker VX Ace: Dragon Maid's Erotic Notepad picks menu items with the mouse, the trackpad and touch. Before, any tap chose the highlighted item, so tapping the title's recollection item started a new game (#166).
- AliceSoft System 4: Rance IX no longer rewrites one of its files several times a frame during story scenes (#169).
- AliceSoft System 4: Rance 02's saves no longer grow with every character of text shown. Saves still load both ways with the PC game (#169).

## Known issue

- Dragon Maid's Erotic Notepad: the recollection screen stays black. A fix is in progress.

## What wasn't tested

- No physical device was used.
- Ren'Py, KiriKiri and NekoSDK movies were checked on an iPad simulator and in the Mac app; the Intel half of the Mac app wasn't run.
- Walking by clicking on the map in Dragon Maid's Erotic Notepad wasn't checked.
- No code review was done on this release.
