Adds Ren'Py on iPhone and iPad, and replaces the Ludusavi folder setting with save sync that logs in to your backup server itself over SSH and rsync. On iOS, mouse-driven games now take taps where you touch.

## Downloads

- `VNDegen-0.4.0-macOS.zip` for Mac (macOS 15 or later). It is ad-hoc signed: right-click VNDegen and choose Open the first time, or run `xattr -dr com.apple.quarantine /Applications/VNDegen.app`.
- `VNDegen-0.4.0.ipa` for iPhone and iPad (iOS 18 or later). Update it from the AltStore or SideStore source (`https://raw.githubusercontent.com/ChronoStriker1/vndegen/main/altstore/source.json`), or sideload it with Sideloadly.

## New

- Ren'Py games run on iPhone and iPad, in VNDegen's window, on the Ren'Py 8.5.3 engine built into the app. Ren'Py 7 and 6.99 games run on it too, with fixes VNDegen applies in memory. 15 of the 16 Ren'Py 7 games in the maintainer's library reach their main menu. A Ren'Py 7 game's page says whether it is known to work and whether it reached its main menu on this device.
- Ren'Py games on iPhone and iPad take touches directly. The backtick, the controller's Options and Home buttons, and the small corner button open the VNDegen menu.
- On Mac, a Ren'Py game's page has a Ren'Py runtime option that runs it on the other bundled runtime.
- Save sync with Ludusavi now logs in to your backup server over SSH and syncs with rsync. No shared folder is needed. In Settings, enter the server, user, and the Ludusavi folder, then add the key VNDegen shows to the server's `authorized_keys`. Test Connection shows the server's key fingerprint and remembers it, and refuses to connect if it later changes. The README has the steps.
- Games match their Ludusavi entries on their own, through Steam IDs and Ludusavi's game list. You can still pick an entry by hand.
- Before a game starts, VNDegen offers a newer backup from another device. If both this device and the backup changed, it asks which to keep. With automatic backup on, a game's saves are backed up when it closes, unless the server also has newer saves.
- A game's Saves page lists every backup with its date and device, previews what a restore would change, and can undo the last restore.
- On iPhone and iPad, Mouse has a Touch or Cursor choice. Touch, the new default, sends taps to the game where you touch. Cursor is the earlier trackpad-style pointer. Controller has a Mouse checkbox: off by default, so the game ignores touches, and on to use Touch or Cursor alongside the controller. Earlier settings keep their behavior.

## Changed

- The Ludusavi folder setting is gone. Set up the server in Settings to keep syncing saves.
- VNDegen does not delete old backups on the server. It drops backups past Ludusavi's retention limits from the backup list, and Ludusavi on your PC or Deck deletes their folders the next time it backs up that game.
- Each VNDegen device names its backup folders with a short device ID, so two devices never write the same folder.

## Known limits

- When VNDegen adds a backup, Ludusavi on a PC that syncs with rclone shows its cloud conflict prompt at its next backup of that game. Choose Download. Upload would remove VNDegen's backup from the server.
- No lock is shared with Ludusavi on other devices. If another device backs up the same game within about a second of VNDegen, one of the two backup lists can be lost. Its backup files stay on the server.
- Ren'Py can't load saves made by a newer Ren'Py, so saves made in VNDegen may not load in an older game's PC version. The Saves page warns before a backup when that applies. A Mac loads a Ren'Py 7 game's iPhone or iPad saves only once that game's Ren'Py runtime option is set to Ren'Py 8.
- On Mac, metadata API keys and the app passcode are in the Keychain, which asks for your password once after each update. VNDegen's SSH key is kept in a file instead, so save sync never asks.
- The new touch modes were tested on the simulator, not yet with a hardware keyboard or on a real device.
- Changes to button mapping made while a Ren'Py game runs apply on its next launch.
