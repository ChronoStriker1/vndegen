Godot games ask before a link opens your browser.

## Downloads

- `VNDegen-0.59.14-macOS.zip` for Mac (macOS 15 or later). It is ad-hoc signed: right-click VNDegen and choose Open the first time, or run `xattr -dr com.apple.quarantine /Applications/VNDegen.app`.
- `VNDegen-0.59.14.ipa` for iPhone and iPad (iOS 18 or later). Update it from the AltStore or SideStore source (`https://raw.githubusercontent.com/ChronoStriker1/vndegen/main/altstore/source.json`), or sideload it with Sideloadly.
- `VNDegen-0.59.14-LGPL-sources.tar`: the exact source of the LGPL libraries in this release. [docs/relinking.md](https://github.com/ChronoStriker1/vndegen/blob/main/docs/relinking.md) says how to replace one.

## Added

- **BISHOP BSX:** Mesu Kyoushi 3 and 4's free-sight meter. On the dress screen, FACE, BUST and HIP pick a fixed view of close-ups, and dragging the knob or clicking the meter sets your own. The view stays on later lines and is kept in saves, so it moves with the PC both ways.

## Fixed

- **Godot:** a game's link, such as a Discord or Patreon button, asks "Open this page in your browser?" first, with Cancel as the default, on Mac, iPhone and iPad. Godot games never open files or other apps (#193). NekoSDK's web links use the same prompt.

## What wasn't tested

- No physical device was used. These were checked in the Linux test build, the Mac app and an iPad simulator.
- No Godot 3 game in the library opens links, so Godot 3's prompt was checked only in tests.
- No code review was done on this release.
