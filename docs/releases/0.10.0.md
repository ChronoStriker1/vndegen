Adds Artemis engine games on Mac, iPhone and iPad.

## Downloads

- `VNDegen-0.10.0-macOS.zip` for Mac (macOS 15 or later). It is ad-hoc signed: right-click VNDegen and choose Open the first time, or run `xattr -dr com.apple.quarantine /Applications/VNDegen.app`.
- `VNDegen-0.10.0.ipa` for iPhone and iPad (iOS 18 or later). Update it from the AltStore or SideStore source (`https://raw.githubusercontent.com/ChronoStriker1/vndegen/main/altstore/source.json`), or sideload it with Sideloadly.

## New

- Artemis games run inside VNDegen's window on art3m1s-core, an open-source Rust reimplementation of the Artemis runtime, built into the app. It draws through Metal and runs the games' Lua on Lua 5.1 with no JIT. The core is under MPL-2.0, and its source and every change VNDegen made to it are in `Engines/Artemis/`.
- VNDegen finds a game by its `.pfs` archive (`pf2`, `pf6` or `pf8`) and the patch volumes beside it, or by the `system.ini` of an unpacked game, up to two folders down.
- Saves are the PC engine's own files, in both versions it writes (1000 and 1002). A save made in VNDegen loads in the PC version at the same page, and the other way round, read history included. Saves go under the folder name the PC version uses, in AppData or beside the game, so Ludusavi backups from Windows restore there, including backups whose folder name a non-Japanese Windows garbled.
- Pages break where the PC version breaks them, and games that ship bitmap `.rft` fonts draw their English text from those fonts.
- Artemis games start with the "Keyboard and mouse" layout. Confirm reads on, Cancel presses Escape, Menu right clicks, Dash skips, and the page buttons open the message history. A game's own name-entry dialog answers to a controller.
- Files are found whatever case the game names them in.

## Known limits

- Movies don't play, and each counts as finished at once.
- Screen effects written as HLSL shaders, such as sepia and negative, don't show.
- Steam functions in Steam builds do nothing.
- In games with bitmap `.rft` fonts, only ASCII comes from those fonts. Japanese text and symbols use MS Gothic, so a line with them can wrap differently than on the PC.
- A game's own native dialog, such as a name entry, shows as a system alert.
- In one test game, the screen stays black after a quick load until the next click, which shows the saved page.
- Tested with the 8 Artemis games in the library. All reach their title, play, save and load on the Mac and the iPad simulator, including from a library with every file name's case changed, and one also on the iPhone simulator. `docs/artemis.md` has the details.
