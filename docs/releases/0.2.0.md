Adds TyranoScript, the second engine.

## Downloads

- `VNDegen-0.2.0.ipa` for iPhone and iPad (iOS 18 or later). Update it from the AltStore or SideStore source (`https://raw.githubusercontent.com/ChronoStriker1/vndegen/main/altstore/source.json`), or sideload it with Sideloadly.
- `VNDegen-0.2.0-macOS.zip` for Mac (macOS 15 or later). It is ad-hoc signed: right-click VNDegen and choose Open the first time, or run `xattr -dr com.apple.quarantine /Applications/VNDegen.app`.

## New

- TyranoScript and TyranoBuilder games: plain browser builds, NW.js builds, and Electron builds, including games packed in `app.asar`. Tested with three games covering Tyrano 4.50 and 5.20, Japanese text, and a controller from title screen through choices, saving, and loading.
- Saves stay in the game folder as on PC. Games that save to browser storage keep it per game inside VNDegen.
- Ogg audio plays on iPhone and iPad: VNDegen converts each track to AAC the first time it plays and caches it.

## Fixed

- Archive import keeps every part of a split archive safe from cleanup while it is open, and follows an archive that moved during import.
- A security fix for how game files are opened, so a game folder cannot read files outside itself through a symlink.

## Known limits

- Typing a name in a game with a controller does not bring up the keyboard; use touch or a hardware keyboard.
- Ogg files that use Opus instead of Vorbis may play silent.
- In some TyranoScript games, VNDegen's menu button sits over the game's own button in the top right corner.
- The Hidden games and Metadata sources settings pages still need touch or a mouse.
