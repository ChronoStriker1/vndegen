Save sync now connects to your Ludusavi backups over SMB, the way Ludusavi's own SMB cloud setting does, instead of over SSH.

## Downloads

- `VNDegen-0.4.3-macOS.zip` for Mac (macOS 15 or later). It is ad-hoc signed: right-click VNDegen and choose Open the first time, or run `xattr -dr com.apple.quarantine /Applications/VNDegen.app`.
- `VNDegen-0.4.3.ipa` for iPhone and iPad (iOS 18 or later). Update it from the AltStore or SideStore source (`https://raw.githubusercontent.com/ChronoStriker1/vndegen/main/altstore/source.json`), or sideload it with Sideloadly.

## Changed

- Save sync reaches the SMB share your Ludusavi backups are on. Settings asks for the same values as Ludusavi's SMB cloud setting: host, port (445), guest or a user and password, and the path, which starts with the share name, such as `games/Ludusavi`. VNDegen talks to the share through rclone's own code built into the app, the same code Ludusavi runs.
- On iPhone and iPad the password is kept in the Keychain. On a Mac it is kept in a file only your user can read, so app updates don't ask for your password.
- SSH is gone: no key to add to the server and no server fingerprint to trust. Save sync set up over SSH in 0.4.0 stays off until you enter the SMB share in Settings, and VNDegen deletes the SSH key it made. You can remove that key's line from the server's `authorized_keys`.
- Uploads only add files. VNDegen still never deletes backups on the server, and it still checks that the backup list didn't change on the server before replacing it.

## Known limits

- When VNDegen adds a backup, Ludusavi on a PC or Deck that syncs with rclone shows its cloud conflict prompt at its next backup of that game. Choose Download. Upload would make rclone delete VNDegen's backup from the share.
- No lock is shared with Ludusavi on other devices. If another device writes the same game's backup list in the few milliseconds between VNDegen's last check and its replace, one of the two backup lists can be lost. Its backup files stay on the share.
- Only SMB is supported for now. Ludusavi's other cloud types are on the roadmap.
