Fixes for TyranoScript games from the code review.

## Downloads

- `VNDegen-0.2.3.ipa` for iPhone and iPad (iOS 18 or later). Update it from the AltStore or SideStore source (`https://raw.githubusercontent.com/ChronoStriker1/vndegen/main/altstore/source.json`), or sideload it with Sideloadly.
- `VNDegen-0.2.3-macOS.zip` for Mac (macOS 15 or later). It is ad-hoc signed: right-click VNDegen and choose Open the first time, or run `xattr -dr com.apple.quarantine /Applications/VNDegen.app`.

## Fixed

- Ogg audio is now decoded inside the game's page (libvorbis compiled to WebAssembly) instead of by VNDegen itself, so a damaged audio file can no longer crash or corrupt the app. Decoding is limited to two tracks at a time and an 11-minute track length, and the decoded cache is capped.
- A malformed `app.asar` package is rejected cleanly instead of crashing VNDegen during a library scan.
- `Config.tjs` is read exactly the way TyranoScript reads it, so VNDegen backs up the right kind of saves.
- Ludusavi backups of Electron TyranoScript games include the save key, so saves restored from another device load without Tyrano refusing them.
- Browser-storage saves whose names differ only in upper and lower case no longer overwrite each other on Mac, and a failed save write can no longer wipe saves from memory.
- A controller can reach every choice in TyranoScript games that mix their own buttons with Tyrano's.

## Known limits

- Ogg tracks longer than about 11 minutes, and chained Ogg files past their first part, play silent on iPhone and iPad.
- Typing a name with a controller does not bring up the keyboard; use touch or a hardware keyboard.
