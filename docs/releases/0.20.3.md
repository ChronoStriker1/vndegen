Skip and Auto in TyranoScript games now work the way they do in other visual novels.

## Downloads

- `VNDegen-0.20.3-macOS.zip` for Mac (macOS 15 or later). It is ad-hoc signed: right-click VNDegen and choose Open the first time, or run `xattr -dr com.apple.quarantine /Applications/VNDegen.app`.
- `VNDegen-0.20.3.ipa` for iPhone and iPad (iOS 18 or later). Update it from the AltStore or SideStore source (`https://raw.githubusercontent.com/ChronoStriker1/vndegen/main/altstore/source.json`), or sideload it with Sideloadly.

## Fixes

- TyranoScript: tapping a game's Skip or Auto button works at any moment, including while a line is typing or the game is waiting. Before, the tap was ignored then.
- TyranoScript: a second tap turns the mode off. Before, it started the mode again.
- TyranoScript: the running button glows blue, so you can see which mode is on.
- TyranoScript: Skip passes unread text, unless the game's own settings screen stores a choice about that. Most games stopped Skip at the first unread line, so the button looked dead on a first playthrough.

## Known limits

- TyranoScript: these changes were checked on the iPad simulator, not on the Mac app or a real iPad.
