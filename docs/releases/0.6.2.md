The whole app now works with a controller alone, with an on-screen keyboard the controller types on.

## Downloads

- `VNDegen-0.6.2-macOS.zip` for Mac (macOS 15 or later). It is ad-hoc signed: right-click VNDegen and choose Open the first time, or run `xattr -dr com.apple.quarantine /Applications/VNDegen.app`.
- `VNDegen-0.6.2.ipa` for iPhone and iPad (iOS 18 or later). Update it from the AltStore or SideStore source (`https://raw.githubusercontent.com/ChronoStriker1/vndegen/main/altstore/source.json`), or sideload it with Sideloadly.

## New

- Every screen takes controller focus: the library, game pages, every Settings page, the button mapping editor, adding a game, the lock screen, and every dialog and sheet. A sheet that opens over another, such as a license over the artwork editor, gets focus too.
- Text fields open an on-screen keyboard when you press A on them. A types the focused key, X deletes, LB toggles shift, RB switches to symbols, Y finishes, and B closes it without changes. It covers the Ludusavi server fields and game search, metadata source keys and search, and the folder name and password when adding a game.
- Hidden games can be set up by controller: set, change or remove the passcode with the D-pad and A, and turn biometrics on or off.
- Adding a game by controller lists the archives in VNDegen's own folder. The Files and Photos pickers need touch or a mouse, and now say so on screen.
- The button mapping editor has Reset, which returns a game to its engine's default layout, and LB and RB jump between groups of buttons. Remapping A or B never changes how the editor or the VNDegen menu respond.
- License text scrolls by controller.

## Fixed

- On the Mac, Settings rows now show controller focus. Before, no row showed where focus was.
- The "Can't launch" alert closes with A or B. Before, a controller couldn't close it.

## Known limits

- Checked by controller alone on the Mac app and on iPad and iPhone simulators, with simulated controller input. Not yet checked with a real controller.
- Retrying Face ID with X wasn't tested, because the simulators have no biometrics. The Ludusavi game search wasn't tested against a real share.
- On iPhone and iPad, iOS may keep a controller's Home button for itself. The touch gamepad's house button and the corner menu button always open the VNDegen menu.
