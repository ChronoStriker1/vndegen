First test build. RPG Maker MV and MZ games run on Mac, iPhone, and iPad, verified with No Socks RPG.

## Downloads

- `VNDegen-0.1.0.ipa` for iPhone and iPad (iOS 18 or later). It is unsigned. Install it with Sideloadly or AltStore, which sign it with your Apple ID. A free Apple ID signature lasts 7 days.
- `VNDegen-0.1.0-macOS.zip` for Mac (macOS 15 or later). It is ad-hoc signed, so macOS blocks it on first open. Unzip it, move `VNDegen.app` to Applications, then right-click it and choose Open, or run `xattr -dr com.apple.quarantine /Applications/VNDegen.app`.
- `SHA256SUMS` lists the checksums.

## What works

- RPG Maker MV and MZ games, unmodified, with saves in the same `.rmmzsave` format as the PC version. Encrypted assets, WebM movies, and Effekseer effects play.
- The library hub with artwork and metadata from Steam, SteamGridDB, IGDB, and VNDB, and per-device layouts for iPhone, iPhone Duo, iPad, and Mac.
- Touch, mouse and keyboard, and game controllers. A controller drives the library, game pages, and their sheets. The Hidden games and Metadata sources settings pages still need touch or a mouse. On iPhone and iPad, an on-screen gamepad or virtual mouse appears when no controller is connected.
- Hidden games behind Face ID, Touch ID, or a passcode.
- In-game orientation lock: landscape by default on iPhone, and on iPad only when the app is full screen.
- Ludusavi backup and restore against an existing Ludusavi folder, including a network share connected in the Files app.
- Importing games from zip, RAR, and 7z archives with Add game.

## Adding games

- iPhone and iPad: Files, On My iPhone (or iPad), VNDegen, Games, one folder per game. Or use Add game with an archive.
- Mac: `~/Games/VNDegen`, one folder per game.

## Known limits

- Only RPG Maker MV and MZ games run so far. Other engines show as unsupported.
- Not yet tested on a physical iPhone, iPad, or controller.
- Password-protected RAR and 7z archives cannot be imported. Password-protected zips can.
- "Delete archive after import" may delete the original of a file synced by Dropbox or OneDrive. Leave it off for synced files. Fixed in the next release.
