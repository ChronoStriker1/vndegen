RPG Maker XP, VX and VX Ace games now run on VNDegen's own RGSS runtime instead of mkxp-z, so the app no longer contains a GPL engine.

## Downloads

- `VNDegen-0.12.0-macOS.zip` for Mac (macOS 15 or later). It is ad-hoc signed: right-click VNDegen and choose Open the first time, or run `xattr -dr com.apple.quarantine /Applications/VNDegen.app`.
- `VNDegen-0.12.0.ipa` for iPhone and iPad (iOS 18 or later). Update it from the AltStore or SideStore source (`https://raw.githubusercontent.com/ChronoStriker1/vndegen/main/altstore/source.json`), or sideload it with Sideloadly.

## New: VNDegen's RGSS runtime

- RPG Maker XP, VX and VX Ace games run on a runtime written for VNDegen from the games' files, RPG Maker's own help files and black-box checks, MIT licensed like the rest of the app. `docs/rgss-cleanroom.md` lists its sources.
- The games' scripts run on Ruby 3.4 (BSD-2) with no JIT, with the Ruby 1.8 and 1.9 behaviour older games expect. The runtime draws each frame on the CPU and shows it through Metal.
- Packed games (`Game.rgssad`, `Game.rgss2a` and `Game.rgss3a`) and unpacked ones both run, and the RTPs installed in the app still work.
- Saves stay in the PC format. VX saves work both ways, and saves made in VNDegen from XP and VX Ace games load in the PC engines.
- These games now also run on Mac computers with an Intel processor.
- MIDI music in these games plays through the General MIDI SoundFont in Settings > MIDI music, including one you choose.
- With mkxp-z gone, no GPL component is left in VNDegen. Releases up to 0.11.0 were GPL-3.0 as a whole because of it.

## Known limits: RPG Maker XP, VX and VX Ace

- Movies (`Graphics.play_movie`) don't play.
- Message boxes a game shows go to its log instead of stopping the game.
- F12's reset isn't available, and tilemap flash data isn't drawn.
- Windows API calls work only for the ones the test games make. A game that needs another one may stop with an error, which the game page shows.
- Loading a save made on the PC in an XP or VX Ace game hasn't been checked yet.
- Tested with 4 test games, one or more of each version. All reach their title, play and load saves on the Mac and the iPad simulator, pass the case check, and hold 60 fps. One also saves in the app on the Mac, iPad and iPhone simulators, and two run on the iPhone simulator. Games with weather effects or animated battles weren't reached. `docs/rgss.md` has the details.
