Fixes for adding games from archives on iPhone and iPad.

## Downloads

- `VNDegen-0.1.2.ipa` for iPhone and iPad (iOS 18 or later). Update it from the AltStore or SideStore source (`https://raw.githubusercontent.com/ChronoStriker1/vndegen/main/altstore/source.json`), or sideload it with Sideloadly.
- `VNDegen-0.1.2-macOS.zip` for Mac (macOS 15 or later). It is ad-hoc signed: right-click VNDegen and choose Open the first time, or run `xattr -dr com.apple.quarantine /Applications/VNDegen.app`.

## Fixed

- Choose Archive on iPhone and iPad now uses the system file picker the way Apple presents it. Before, picking a file and tapping Open could do nothing.
- Dragging a zip, RAR, or 7z from the Files app onto VNDegen now works on iPhone and iPad, on the import screen and on the library.

## New

- Open in VNDegen: in Files, tap an archive, then Share, then VNDegen, and the import screen opens with it. On a Mac, use Open With.

## If adding a game still fails

VNDegen now logs every file picker result. Connect the iPhone to a Mac, open Console, select the iPhone, search for `archiveimport`, then try again. The log line shows whether the picker handed the file to VNDegen.

## Known limits

- Only RPG Maker MV and MZ games run so far.
- The Hidden games and Metadata sources settings pages still need touch or a mouse.
