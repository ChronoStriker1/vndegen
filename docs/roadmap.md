# Roadmap

Agreed with the maintainer on 2026-10-25, and reordered on 2026-11-09. Engine order comes from `docs/engine-survey.md`. Release notes are in `docs/releases/`.

## Shipped
- RPG Maker MV/MZ on Mac, iPhone, and iPad (0.1.0).
- Archive import from zip, RAR, and 7z (0.1.0, fixes through 0.1.4).
- Ludusavi backup and restore through a folder picked in the app (0.1.0), replaced in 0.4.0.
- TyranoScript (0.2.0, fixes through 0.3.2).
- Control methods and button mapping (0.2.1).
- Ren'Py on macOS (0.3.0, fixes through 0.3.2).
- Ren'Py on iPhone and iPad (0.4.0). What was built is in "Phase 2 on iOS" in `docs/renpy-spike.md`.
- Ludusavi built into the app (0.4.0). VNDegen connects to the backup server itself over SSH with rsync, matches games through Ludusavi's manifest, and builds in Ludusavi's backup features.
- Touch and Cursor mouse modes on iPhone and iPad, and the controller's Mouse option (0.4.0).
- Fixes for Touch mode and for quitting on a landscape iPhone, Ren'Py games two folders deep, and no control method for Ren'Py on iPhone and iPad (0.4.1).
- Xbox gamepad controls by default for the touch gamepad and real controllers, every Xbox button in the mapping editor with an RPG Maker preset, touch buttons that press on touch-down, a cross-shaped D-pad, and the iPad tilt-shift blur fix (0.4.2).
- Ludusavi save sync over SMB, with Ludusavi's SMB settings and rclone's own code built into the app, replacing SSH and rsync (0.4.3).
- A fix for RPG Maker MZ's Ogg decoder reusing IDs, which stopped games with "RangeError: length cannot be negative" (0.4.4).
- RPG Maker XP, VX, and VX Ace on Mac, iPhone, and iPad, built on mkxp-z's libretro core in the app, Apple silicon only on Mac, with the RTPs downloaded and installed in the app (0.5.0). VNDegen's own runtime replaced mkxp-z in 0.12.0. `docs/rgss-spike.md` records the first engine.
- License notices in Settings, Licenses, for every third-party component in the app (0.5.0).
- The real fix for RPG Maker MZ's "RangeError: length cannot be negative": sounds with Ogg names that hold WAV or MP3 data play through the system decoder, and a decoder failure no longer stops the game (0.5.1).
- KiriKiri 2 and KiriKiri Z on Mac, iPhone, and iPad, built on krkrsdl3, with the common ciphers, Windows plugins, and movie formats built in (0.6.0).
- Controller mouse emulation (0.6.1): sticks and buttons can move the pointer, turn the mouse wheel, and open the on-screen keyboard. KiriKiri and TyranoScript games start with "Keyboard and mouse", the layout of Steam's template, and the mapping editor also offers "Mouse", "RPG Maker controls", and "Xbox gamepad".
- An RPG Maker MZ fix (0.6.1): looping WebM movies made from GIFs, which WebKit takes for shorter than they are, now play at their stated length, so they no longer stutter or drift from their sound. Movie frames are uploaded only when they change, and a clip's first pass no longer pauses.
- An RPG Maker MZ fix (0.6.1): quick controller, touch gamepad, and key presses all reach the game. Each press and release reaches the game's input on its own update, and a VisuStella Core Engine input clear no longer drops the presses that follow it, so timed attacks that need several quick presses succeed.
- The whole app works with a controller alone (0.6.2): every screen, Settings page, dialog and sheet takes controller focus, text fields open an on-screen keyboard the controller types on, the mapping editor has Reset and LB and RB group jumps, and import lists archives in VNDegen's folder. The Files and Photos pickers say they need touch or a mouse. Settings rows on the Mac show controller focus.
- iPad windows (0.7.0): VNDegen fits small and odd window sizes on iPad. The library, game pages, the in-game menu, the touch gamepad, and every engine fit the window and keep clear of iPadOS's window controls. A game in a window follows the window's shape. Checked by laying the app out at sizes down to 320 points wide and in real windows on the iPad simulator. Real drag-resizing, tiling, and Slide Over couldn't be driven in the simulator.
- Game files found whatever case the game names them in, for every engine (0.7.0). iPhone and iPad disks tell `Img/Title.PNG` from `img/title.png`, and Windows games often mix the two. Every engine plugin must pass the case check in [development.md](development.md#file-name-case).
- Flash (0.7.0): Flash projectors, `.swf` movies, and HTML launcher pages run in Ruffle in VNDegen's web view, with ActionScript 1, 2, and 3, saves in Flash's own `.sol` files, and every input method. All 14 library Flash games reach their title and play on the Mac and the iPad simulator, and the 12 that save also save and load.
- Windows fonts (0.7.0): games that ask for MS Gothic, MS PGothic, MS Mincho, Arial, Tahoma and other Windows fonts by name get free fonts with the same metrics, as under Proton, in RPG Maker MV and MZ, TyranoScript, KiriKiri, RPG Maker XP, VX and VX Ace, and Flash. One table of font name substitutions serves every engine. Chinese and Korean substitutes are a download in Settings.
- NScripter (0.8.0), on VNDegen's own clean-room runtime, MIT licensed, on Mac, iPhone, and iPad. It reads `.nsa`, `.sar`, and `.ns2` archives and plays Ogg and WAV sound and MPEG-1 movies. Saves are the PC engine's own files, byte for byte. All 6 test games reach their title, play, save, and load on the Mac and the iPad simulator, and hold 60 fps in dungeon walking and movies. `docs/nscripter.md` has the details and `docs/nscripter-cleanroom.md` the sources. The shared FrameHost module that presents its frames and plays its sound is there for the other new runtimes.
- An RPG Maker MV fix (0.8.1): games that ship only Ogg audio, which every MV game in the library does, have sound. VNDegen decodes their Ogg files in the page instead of asking for `.m4a` files they don't have.
- NScripter fixes (0.8.2): the `breakup.dll`, `lngtwave.dll` and `trvswave.dll` effects drawn as on Windows, MP3 sound, input and yes/no boxes laid out as on Windows, global variables kept when the app is killed, saves made inside subroutines byte-identical to the PC's, and sound decoded off the audio thread. Only features a library game uses were built. The rest stay in `docs/nscripter.md`'s Known limits.
- NScripter features for more games (0.8.3): CD music from a game's `CD` folder, Lua scripts on an embedded Lua 5.1, NBZ voices, LZSS archive entries, the `MSpDraw.dll` drawing plugin, and backquoted English text. Built for the 4 library games that use them.
- Godot (0.9.0), on Godot 4.7.2 for Godot 4 games and Godot 3.6.3 for Godot 3 games, on Mac with Apple silicon, iPhone, and iPad. Packs load unchanged, from a `.pck` or from inside the `.exe`. Godot 4 draws through Metal, and Godot 3 through OpenGL on Mac and ANGLE on iPhone and iPad. Saves go where Windows keeps them. All 4 test games reach their title, save, and load on the Mac and the iPad simulator, and pass the case check. Two library games can't be supported: one needs Steam ownership, and one has an encrypted pack and Windows-only GDExtensions. `docs/godot.md` has the known limits.
- Artemis (0.10.0), on art3m1s-core (MPL-2.0), an open-source Rust reimplementation of the Artemis runtime, with VNDegen's patches, on Mac, iPhone, and iPad. It draws through Metal and runs the games' Lua on Lua 5.1 with no JIT. Saves are the PC engine's own files in both versions it writes, so they load in the PC version at the same page and the other way round. Pages break where the PC version breaks them. All 8 test games reach their title, play, save, and load on the Mac and the iPad simulator and pass the case check, and one also on the iPhone simulator. Movies and HLSL shader effects don't play. `docs/artemis.md` has the known limits.
- Godot games that use Steam or encrypted packs (0.10.0): a stand-in for GodotSteam that answers as offline Steam, Epic Online Services class names for Godot 4, Godot 4 encrypted packs with the key read from the game's `.exe`, and `res://` paths outside the pack resolved to the game's folder.
- Wolf RPG Editor (0.11.0), on VNDegen's own runtime, written in C++ and MIT licensed, on Mac, iPhone, and iPad. It reads loose data, Wolf RPG Editor 2's `.wolf` archives and its encrypted basic data, and plays Ogg, MP3, WAV, and MIDI. Saves are the PC engine's own files and load in the PC engine and the other way round. All 3 test games reach their title, play, save, and load on the Mac and the iPad simulator, pass the case check, and hold 60 fps in battle, and one also plays on the iPhone simulator. 13 more library games play in the Linux test build. `docs/wolfrpg.md` has the known limits.
- A shared MIDI player (0.11.0), vnmidi on TinySoundFont, with the FluidR3 Mono SoundFont built in and a Settings option to choose your own. `docs/midi.md` has the details.
- Game page screenshots and cleaner artwork (0.11.0): the About section shows Steam or IGDB screenshots, the artwork picker hides another source's copy of the same picture, and iPhone portrait art takes less height.
- Library views (0.11.0): Header list, Capsule rows, and Featured layouts for the library home, switched from the top bar, with a default per device.
- RPG Maker XP, VX, and VX Ace on VNDegen's own clean-room RGSS runtime (0.12.0), replacing mkxp-z. An unused copy of mkxp-z's framework stayed in releases until 0.18.0. It runs the games' Ruby scripts on MRI Ruby 3.4 (BSD-2) with no JIT, draws on the CPU through FrameHost, and plays MIDI through the shared player. Intel Macs run these games too. All 4 test games reach their title, play, save, and load on the Mac and the iPad simulator and pass the case check, and two run on the iPhone simulator. Saves are the PC format: VX both ways, and VNDegen's XP and VX Ace saves load on the PC. `docs/rgss.md` has the known limits and `docs/rgss-cleanroom.md` the sources.
- AliceSoft System 3 (0.13.0), on VNDegen's own clean-room runtime, MIT licensed, on Mac, iPhone, and iPad. All 10 test games reach their title and play on the Mac and the iPad simulator, 9 save and load there, one runs on the iPhone simulator, and Panyon's battles hold 60 fps. `docs/system3.md` has the known limits and `docs/system3-cleanroom.md` the sources.

## Licenses
VNDegen stays free to distribute, through its GitHub releases. It won't go on the App Store (maintainer, 2026-11-16). Releases up to 0.11.0 include mkxp-z, the first RGSS runtime, so they are GPL-3.0 as a whole, as the README's License section explains. From 0.12.0 VNDegen's own RGSS runtime replaces it. Releases 0.12.0 to 0.17.0 still carried an unused copy of mkxp-z's framework, left over in the folder they were built in, so they are GPL-3.0 as a whole too. From 0.18.0 no GPL component is left:
- VNDegen's own MIT runtimes replace the GPL ones. The clean-room RGSS runtime replaced mkxp-z in 0.12.0. NScripter and AliceSoft System 3 and System 4 are clean-room from the start, so VNDegen never ships ONScripter, xsystem35, or xsystem4. The clean-room runtimes are written from the game files and the engines' own documentation, never from GPL code. The original engines run under Wine only to settle open questions, such as the PC save format. With no GPL runtime left, the app is MIT for its own code plus permissive notices.
- New engines use only permissive licenses: MIT, BSD, zlib, Apache-2.0, ISC, MPL-2.0, or public domain, and OFL-1.1 for fonts. One exception, agreed with the maintainer: NekoSDK's and SiglusEngine's WMV movies use the LGPL FFmpeg the app already ships for KiriKiri, because Apple doesn't decode WMV and no permissive decoder is known. The KiriKiri framework exports a small decoder over it, `vnffmovie`, which the NekoSDK and SiglusEngine runtimes find at run time, so the app links FFmpeg once ([video.md](video.md#vnffmovie-wmv-through-the-apps-ffmpeg)).
- The LGPL libraries are each in a library or file of their own, which a changed copy can replace, as the LGPL asks: FFmpeg 8.1.2 is `FFmpeg.framework`, Ren'Py's iOS libraries (FFmpeg 4.3.1, FriBidi and Pygame's blitter) are `RenPyRuntime.framework`, the Mac's are Ren'Py's `librenpython.dylib`, and chardet is Python bytecode. rclone's one LGPL-3.0 module, `github.com/cloudsoda/sddl`, which its SMB code imports and never uses, is replaced by a stub of VNDegen's own. Each release carries the libraries' exact source as `VNDegen-<version>-LGPL-sources.tar`. [relinking.md](relinking.md) has the steps.

## Runtime packages
When a game needs a runtime package that VNDegen doesn't bundle, such as the RPG Maker RTP, the app offers to download it from its official source and install it, in addition to importing it from a folder. The `RuntimePackages` module does this: an engine describes each package with its official URL and pinned SHA-256 (`RuntimePackage` in VNCore), and the module downloads, checks, and unpacks it, with an Inno Setup reader for installers like the RPG Maker RTPs'. The RPG Maker 2000 and 2003 RTPs can use it the same way.
